# Cloud Cam 📸  

Cloud Cam is a web application that allows users to capture photos directly from their browser and store them in the backend for secure access and retrieval.  

## Features  
- Capture photos using the web camera  
- Store photos securely in the backend  
- Retrieve and manage stored images  

## Technologies Used  
- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js, Express.js  
- Storage: mongodb 


## Future Enhancements  
- User authentication for secure access  
- Cloud storage integration  
- Image filters and editing options
